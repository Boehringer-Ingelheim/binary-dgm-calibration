# Binary DGM Calibration
This repository contains R code implementing a structure-preserving calibration procedure for binary-outcome data-generating mechanisms to enure a desired level of prognostic covariate strength and precision gain for covariate-adjusted estimation of marginal treatment effects. 

The underlying algorithm was developed and is described in the manuscript *Quantifying and calibrating precision gain from covariate adjustment in clinical trials with binary endpoints* (Hammerschmied, Stock, & Schnuerch, 2026).
